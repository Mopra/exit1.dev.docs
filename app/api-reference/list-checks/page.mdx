# List Checks

Retrieve a list of all monitoring checks in your account.

## Endpoint

```
GET /v1/public/checks
```

## Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | integer | 25 | Number of results per page (max 100) |
| `page` | integer | 1 | Page number for offset pagination |
| `cursor` | string | - | `nextCursor` value from a previous response, for cursor pagination |
| `status` | string | `all` | Filter by status: `all`, `online`, `offline`, `degraded` or `unknown`. Any other value returns `400` |
| `folder` | string | - | Only checks in this folder, by its full path, such as `Personal/Radio` |
| `recursive` | boolean | `false` | With `folder`, also include checks in its subfolders. Any value other than `true` or `false` returns `400` |
| `includeTotal` | boolean | `true` | Set to `false` to skip counting. `total` and `totalPages` are then `null` |

Checks are returned in the same order as in your dashboard.

## Filtering by Folder

`folder` takes the full path of the folder, with `/` between levels, as it appears in the `folder` field of each check. Leading and trailing slashes are ignored. Without `recursive`, only checks directly in that folder are returned:

```bash
curl -H "X-Api-Key: ek_live_..."   "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?folder=Personal/Radio"
```

Add `recursive=true` to include every subfolder too, so `Personal/Radio/Live` matches but `Personal/Radio-old` does not:

```bash
curl -H "X-Api-Key: ek_live_..."   "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?folder=Personal/Radio&recursive=true"
```

`folder` combines with `status` and both pagination methods. When `folder` is set, `total` is always returned, even with `includeTotal=false`.

## Pagination

The API supports two pagination methods:

### Offset Pagination

Use `page` and `limit` parameters:

```bash
curl -H "X-Api-Key: ek_live_..." \
  "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?page=2&limit=10"
```

### Cursor Pagination

Pass the `nextCursor` value from the previous response as `cursor`. When `cursor` is set, `page` is ignored:

```bash
curl -H "X-Api-Key: ek_live_..." \
  "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?cursor=eyJvcmRlckluZGV4IjoxMDAwLCJpZCI6ImFiYzEyMyJ9&limit=10"
```


Each item in `data` is a check object. See [Get Check](/api-reference/get-check#check-object) for every field. All timestamps are Unix epoch milliseconds.

### `meta`

| Field | Type | Description |
|---|---|---|
| `page` | number | Current page number |
| `limit` | number | Results per page |
| `total` | number \| null | Total matching checks. `null` when `includeTotal=false` |
| `totalPages` | number \| null | Total pages at this `limit`. `null` when `includeTotal=false` |
| `hasNext` | boolean | Whether another page exists |
| `hasPrev` | boolean | Whether a previous page exists. Always `true` when `cursor` is set |
| `nextCursor` | string \| null | Pass as `cursor` to fetch the next page. `null` when the page is empty |

> **Note:** `status` updates in real time on every state change. The timing fields (`lastChecked`, `responseTime`, `lastStatusCode`) are synced on status changes and at least once every 24 hours. For a check that has been stable for a while, `lastChecked` reflects the last sync, not the last probe. For per-probe data, use the [check history](/api-reference/check-history) endpoint.

## Error Responses

| Status | Body | Cause |
|---|---|---|
| 400 | `{"error": "Invalid status. Allowed: all, online, offline, degraded, unknown"}` | Unsupported `status` value |

## Code Examples

### cURL

```bash
curl -H "X-Api-Key: ek_live_your_key_here" \
  "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?limit=10&status=offline"
```

### JavaScript

```javascript
const response = await fetch(
  "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks?limit=10",
  {
    headers: {
      "X-Api-Key": "ek_live_your_key_here",
    },
  }
);
const data = await response.json();
console.log(data);
```

### Python

```python
import requests

response = requests.get(
    "https://us-central1-exit1-dev.cloudfunctions.net/publicApi/v1/public/checks",
    headers={"X-Api-Key": "ek_live_your_key_here"},
    params={"limit": 10}
)
data = response.json()
print(data)
```
