# Domain Intelligence

Domain Intelligence tracks domain registration expiration dates using the RDAP protocol, helping you avoid accidental domain lapses.

> **Note:** Domain Intelligence is available on the **Nano, Pro, and Agency** plans.

## Two ways to use it

You can monitor a domain's expiry in two ways, depending on whether you're already monitoring uptime for that domain.

| Mode | When to use | How it counts |
|---|---|---|
| **Domain-only check** (`type: domain`) | The domain isn't hosting anything you want to probe — e.g. a parked domain, a future-use name, a trademark you're sitting on. | Counts as one check toward your tier's limit, but never executes an uptime probe. |
| **Add-on to an existing check** | You already monitor uptime for a check on this domain. | The DI add-on is free — it doesn't count separately. |

## How It Works

1. You either create a domain-only check (just a bare domain, no URL) or enable Domain Intelligence on an existing check
2. exit1.dev queries RDAP (Registration Data Access Protocol) servers for domain registration data
3. Expiration dates are tracked and monitored continuously, on a schedule that tightens as expiry approaches
4. Alerts are sent at configurable thresholds before the domain expires

## Key Features

- **Domain-only checks** - Track domains you don't host. No uptime probes are sent, so the entry never goes "down".
- **Automatic domain extraction** - For DI on existing checks, the domain is extracted from the check URL automatically
- **RDAP protocol** - Uses the modern, standardized RDAP protocol (with WHOIS fallback for TLDs without RDAP)
- **Configurable alerts** - Set custom alert thresholds (default: 30, 14, 7, 1 days)
- **Renewal detection** - Detects when a domain is renewed and clears expiration warnings

## Supported TLDs

Domain Intelligence supports any TLD that has RDAP service endpoints, which includes most major TLDs:

- `.com`, `.net`, `.org`
- `.io`, `.dev`, `.app`
- Country-code TLDs with RDAP support
- Most new gTLDs

For TLDs without RDAP support, exit1.dev automatically falls back to WHOIS where possible.
